# 程琳杰 · 个人作品集网站

一个纯静态的个人作品集站点：**自动同步 GitHub 仓库**、零依赖、可部署到 GitHub Pages 或绑定自己的域名。
用原生 HTML / CSS / JavaScript 写成，没有构建步骤，不需要 npm。

---

## 一、文件结构

```
.
├── index.html              页面结构（一般不用改）
├── assets/
│   ├── css/style.css       全站样式
│   └── js/
│       ├── profile.js      ★ 全站内容配置（改内容只改这个文件）
│       └── main.js         渲染与交互逻辑
├── CNAME                   绑定自定义域名时才需要（见第五节）
└── README.md
```

---

## 二、部署前必做的一步

打开 `assets/js/profile.js`，把第一段的 GitHub 用户名填上：

```js
base: {
  name: '程琳杰',
  githubUser: 'Jeremy415', // 已填好，项目板块会以此为准
  ...
}
```

填好之后，「项目仓库」板块会展示你的项目。
**没填的话这个板块会自动隐藏**，页面不会出现空白区域。

## 三、怎么改内容

所有文字、项目、技能、经历都在 `assets/js/profile.js` 里，每段都有中文注释。

| 想改什么 | 改哪里 |
|---|---|
| 姓名、邮箱、电话、所在地 | `base` |
| 首屏自我介绍、轮播的身份标签 | `hero` |
| 关于我的段落、右侧信息卡片 | `about`（`facts` 可自由增减） |
| 精选项目（名称、亮点、技术栈、详情页内容） | `featured`（每项里的 `detail` 决定详情页） |
| 技能与说明 | `skills`（填 `level: 0-100` 会显示进度条） |
| 工具箱小标签 | `tools` |
| 工作 / 教育经历时间轴 | `timeline` |
| 证书与荣誉 | `certificates` |
| 联系方式 | `contact` |

改完保存，刷新浏览器即可生效。

## 四、部署到 GitHub Pages（免费）

### 方式 A：独立仓库

1. 新建仓库，例如 `Portfolio`（**不要**勾选 Add README）。
2. 推送代码：

   ```bash
   git init
   git add .
   git commit -m "feat: 个人作品集网站"
   git branch -M main
   git remote add origin https://github.com/你的用户名/Portfolio.git
   git push -u origin main
   ```

3. 仓库页面 → **Settings** → **Pages** → Source 选 `Deploy from a branch`，
   Branch 选 `main` + `/ (root)` → **Save**。
4. 等 1~2 分钟，访问：`https://你的用户名.github.io/Portfolio/`

### 方式 B：个人主页（地址更短，★ 本项目采用这个）

把仓库名设成 **`你的用户名.github.io`**，部署后地址就是：

```
https://你的用户名.github.io/
```

最短最好记，放简历上最合适（一个账号只能有一个）。

## 五、关于域名：你不一定要买

### 方案一：免费用 GitHub 自带的（建议先这样）

上面的 `https://你的用户名.github.io/` 本身就是可用链接，HR 点开就能看，
**不需要买域名、不需要花钱**。缺点是地址带 github.io，不够"个人品牌"。

### 方案二：买一个自己的域名（约 30~100 元/年）

想让链接变成 `chenglinjie.com` 这种，就去注册一个域名。

**在哪买**

| 平台 | 特点 |
|---|---|
| 阿里云（万网）/ 腾讯云 | 国内最常用，中文界面，支付宝付款，需实名认证 |
| Namesilo | 国外老牌，支持支付宝，价格透明，送免费隐私保护 |
| Cloudflare Registrar | 按成本价卖不赚差价，但需要 Cloudflare 账号 + 国际支付方式 |
| Porkbun / Namecheap | 国外常见选择，首年促销多 |

**价格行情参考**

- `.com` 约 ¥70~90/年 ← **最推荐，通用、可信度高**
- `.cn` 约 ¥30~40/年（需实名认证）
- `.dev` / `.me` / `.io` 约 ¥80~300/年
- `.top` / `.xyz` 常有首年几元钱的促销，**但续费会涨回原价**

**买之前注意 4 件事**

1. **看续费价，别只看首年价** —— 很多"首年 9 元"续费要 90 元。
2. **打开 Whois 隐私保护** —— 不然你的姓名、电话、邮箱会被公开在网络上，多数平台免费提供。
3. **域名尽量和名字相关** —— `chenglinjie.com` 比 `ailab2026.com` 更像个人品牌。
4. **先买 1 年试水**，不要一次买 5 年。

**买完怎么绑到 GitHub Pages**

1. 到域名服务商的 DNS 解析后台，添加记录：

   | 类型 | 主机记录 | 记录值 |
   |---|---|---|
   | CNAME | `www` | `你的用户名.github.io` |
   | A | `@` | `185.199.108.153` |
   | A | `@` | `185.199.109.153` |
   | A | `@` | `185.199.110.153` |
   | A | `@` | `185.199.111.153` |

2. 在本项目根目录新建一个名为 `CNAME` 的文件（**没有后缀名**），内容只写你的域名一行：

   ```
   chenglinjie.com
   ```

3. GitHub 仓库 → **Settings** → **Pages** → **Custom domain** 填域名 → **Save**。
4. 等几分钟 DNS 生效后，勾选 **Enforce HTTPS**。证书由 GitHub 自动签发，免费。

### 方案三：其他托管平台

- **Vercel** —— 导入 GitHub 仓库即可，自带 `xxx.vercel.app` 域名，配置最简单。
- **Cloudflare Pages** —— 免费 + 全球 CDN，适合绑自己的域名。
- **腾讯云 / 阿里云静态托管** —— 国内访问快，但如果用国内服务器就**必须 ICP 备案**（1~3 周）。

> **备案提醒**：域名指向 GitHub Pages（境外服务器）**不需要备案**；只有指向国内服务器才需要。

### 我的建议

先用 `你的用户名.github.io` 免费方案，把内容做扎实。
等到真需要往简历上放一个"品牌化"地址时，再花 70 块买个 `.com` 域名接上去，
整个过程不用改任何代码，只是加个 DNS 解析和一个 `CNAME` 文件。

## 六、功能说明

- **项目详情页**：精选项目卡片右下角有「查看项目详情」，点开弹层查看完整介绍。
  内容来自 `featured[].detail`，支持项目背景、核心模块、技术难点与交付成果。
- **项目仓库列表**：数据来自 `profile.js` 的 `repoOverrides`，私有仓库只展示不跳转。
- **仓库筛选与搜索**：按主要语言筛选、按名称 / 描述搜索。
- **打印简历**：首屏「打印简历」按钮调用浏览器打印，页面已内置打印样式，
  浏览器直接"另存为 PDF"就是一份排版干净的简历。
- **深浅色主题**：右上角切换（快捷键 `T`），选择会记住。
- **响应式 + 无障碍**：手机 / 平板 / 桌面自适应，支持键盘导航，
  系统开启「减弱动效」时自动关闭动画。
